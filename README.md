# Dhruva Foot Health Clinic — Website

Official website for **Dhruva Foot Health Clinic**, Advance Center for Diabetic Foot Care, Karimnagar, Telangana.

## Deploying with GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository: **Settings → Pages → Deploy from a branch** → select `main` and `/ (root)`.
3. The site goes live at `https://<username>.github.io/<repo>/`.

## Contents

- `index.html` — the full one-page site (hero, treatments, warning signs, foot-care awareness, doctors, contact)
- `styles.css` — all styling
- `script.js` — mobile navigation
- `assets/` — clinic logo and doctor photos
